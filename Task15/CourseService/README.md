# \# Task 15: Service Registry \& Discovery using Eureka

# 

# \## Description

# This project demonstrates service registry and discovery using Netflix Eureka.

# 

# \## Components

# \- Eureka Server (Port 8761)

# \- Student Service (Port 8081)

# \- Course Service (Port 8082)

# 

# \## Features

# \- Services register with Eureka

# \- Dynamic service discovery

# \- No hardcoded URLs

# 

# \## How to Run

# 1\. Start Eureka Server

# 2\. Start Student Service

# 3\. Start Course Service

# 4\. Open http://localhost:8761

# 

# \## Technologies

# \- Spring Boot

# \- Spring Cloud Netflix Eureka
