# Task 11: Spring Data JPA - Data Access Layer

## Description
This project demonstrates data retrieval using Spring Data JPA.

## Features
- Custom query methods
- Filtering by department and age
- Sorting using Sort
- Pagination using Pageable

## Technologies
- Spring Boot
- Spring Data JPA
- MySQL

## Endpoints
- GET /department/{dept}
- GET /age/{age}
- GET /sorted
- GET /page?page=0&size=2
