# Task 19: Git Repository and Version Control

## Description
This task demonstrates the use of Git for version control.

## Steps Performed
1. Initialized a Git repository
2. Added files to staging area
3. Committed changes
4. Viewed commit history
5. Connected to GitHub remote repository
6. Pushed code to GitHub
7. Updated files and maintained version history

## Commands Used
- git init
- git add .
- git commit -m "message"
- git log
- git remote add origin
- git push

## Outcome
Successfully managed project using Git and GitHub.
