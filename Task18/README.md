# Task 18: Unit Testing for Microservices

## Description
This project demonstrates unit testing in a Spring Boot microservice.

## Features
- Testing service layer logic
- Testing REST controller
- Ensures reliability of microservices

## Technologies Used
- Java
- Spring Boot
- JUnit 5

## Test Cases
- StudentServiceTest → Tests business logic
- StudentControllerTest → Tests REST endpoint

## How to Run
Run using:
mvn test

## Output
All tests should pass successfully.

## Conclusion
Unit testing helps verify correctness of microservice components independently.
