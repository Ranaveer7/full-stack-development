# Task 13: Exception Handling & Validation (Standalone)

## Description
This project demonstrates validation and global exception handling in a Spring Boot REST API.

## Features
- CRUD operations
- Input validation using annotations
- Global exception handling
- JSON error responses

## Technologies
- Spring Boot
- Spring Data JPA
- MySQL

## Endpoints
- POST /products
- GET /products
- GET /products/{id}
- PUT /products/{id}
- DELETE /products/{id}
