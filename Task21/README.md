# Task 21: CI/CD Pipeline using GitHub Actions

## Description
This project demonstrates a simple CI/CD pipeline using GitHub Actions.

## Features
- Automated code checkout
- Automated build using Maven
- Automated testing using JUnit
- Continuous Integration on every push

## Technologies Used
- Java
- Spring Boot
- Maven
- GitHub Actions

## Workflow
1. Code is pushed to GitHub
2. GitHub Actions triggers pipeline
3. Project is built
4. Tests are executed

## Pipeline File
.github/workflows/ci.yml

## Outcome
Successfully implemented CI/CD pipeline for automation.
