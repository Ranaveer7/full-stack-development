# Task 14: Microservices Architecture

## Description
This project demonstrates a simple microservices-based system by splitting a monolithic application into two independent services.

## Services
1. Student Service (Port 8081)
2. Course Service (Port 8082)

## Features
- Independent services
- Separate deployment
- Loose coupling
- Single responsibility

## Technologies
- Spring Boot
- REST APIs

## How to Run
Run both services separately:
- StudentService → localhost:8081
- CourseService → localhost:8082
