# Task 12: Product Management REST API

## Description
This project implements a RESTful API for product management using Spring Boot.

## Features
- CRUD operations (GET, POST, PUT, DELETE)
- JSON request/response
- MySQL database integration

## Technologies
- Spring Boot
- Spring Data JPA
- MySQL

## Endpoints
- GET /products
- GET /products/{id}
- POST /products
- PUT /products/{id}
- DELETE /products/{id}
